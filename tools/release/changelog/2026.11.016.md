## What changed since 2026.11.015

### A launcher inside the game

The game now opens on a launcher of its own instead of FAF's old main menu. Tabs along the top lead to everything below, with Play's modes in a row under them, and the project's emblem shows where FAF's logo was.

- **Play:** FAF's online games and the games on faf-re's own servers in one list, ours first, each card marked P2P or SERVER, with map previews, a details panel with teams and ratings, and the teams on hover. Host and join from it, also when the game is started directly, and on FAF Develop or another featured mod you have installed (the game restarts on its files). Create game filters maps by players and size and sorts them, and says in a tip why a featured mod can't be picked.
- **Matchmaking:** search in FAF's matchmaker queues, with their player counts and round timers, and pick the factions to play.
- **Co-op:** FAF's co-op missions with their fastest completions, hosting and joining one.
- **LAN:** games on your network show up by themselves, with host and connect-by-address dialogs. When the host of a LAN or direct game leaves, the lobby says so and takes you back to the LAN page.
- **Replays:** this computer's replays and FAF's replay vault, to search, download and watch. Replay details show the teams with ratings, who won, rating changes, and game time against real time.
- **Mods and Maps:** FAF's mod and map vaults. Install, remove, turn mods on and off, and host a game on a map, all without restarting.
- **Chat:** FAF's chat channels with their history, who is in them, and their profiles.
- **Player profiles:** ratings, a rating history chart, recent maps with previews, previous names and clan.
- **Changelog:** FAF's patch notes in the launcher's style, each unit's changes as a card with its icon and a table of before, after and the change in per cent.
- **Options:** all of FAF's options with a search, a line under each saying what it does, what you changed with apply and revert, and a Key bindings tab with FAF's presets, keys changed by pressing them, and presets of your own.
- **Sign-in:** FAF's main or test server, each with its own sign-in. The sign-in page opens even with no default browser set, and the sign-in screen has a Copy link button. The launcher keeps you signed in through long sessions and short FAF outages; when the account signs in elsewhere, it says so and stays signed out. The game no longer asks for a profile at the first start: your profile takes your FAF name when you sign in.
- The launcher fits small and narrow windows, and on a first start in a window the game opens at 1600x900 when the screen has room.

### Lobby

- A new lobby screen over FAF's lobby, with each player's flag, rating, CPU score, connection type, ping, ready state, team and faction, and the player's own name colour as FAF's lobby shows it.
- Friends are marked, and a player's slot menu adds them to your FAF friends or removes them.
- Game options and mods each have a full page, with help for each option and on/off switches for mods. By default the lobby shows only the options that differ from the defaults, and your choice is kept.
- A menu opened in the lobby no longer stays on screen after leaving it.

### Gameplay and interface

- **Transport cargo pre-orders:** select units still inside a transport at its drop point, through translucent drop previews, and give them orders (move, attack-move, build, assist, repair) that start when they land. Pre-ordered buildings show ghosts and are checked for placement. The orders go out as ordinary commands when the units land, so replays play them back as recorded. Turn it off in Options > Gameplay > "Transport Cargo Pre-orders" (#375, by GodFuper). A left click no longer picks cargo through a drop preview behind the camera.
- Interface fixes that FAF hasn't released yet (build menu, unit panel and others) now come with the game, each used only while FAF's file is still the one the fix was made for.
- Full screen at a resolution lower than your monitor's fills the whole screen instead of showing a small window in a corner.

### Speed

- Large late-game battles run a little faster: searches for units around a point skip the parts of the map with no units in them.
- AI games run faster: engine calls from AI scripts, the Lua garbage collector and blueprint lookups take less time.
- Text measures character widths without building the character's bitmap first.

### Linux and stability

- On Linux, closing or switching a replay can no longer close another program by mistake (#502, by M3RT1N99).
- The Linux client writes a crash report when it crashes, as the Windows one does (#503, by M3RT1N99), and a crash after a failed assertion still gets its crash report.
- A '%' in a command-line option read from a script no longer makes the game read arguments that were never passed (#501, by M3RT1N99).

### Install

- New one-step installers for Windows and Linux: `scfa-re-setup.exe` and `scfa-re-setup-linux` check the computer, download this release, check its checksum and install it with a shortcut. `--uninstall` removes it again. An install made by the earlier `faf-re-setup` updates the same way.
- The repository is now [Draiget/scfa-re](https://github.com/Draiget/scfa-re); old links forward there.

### For testers and developers

- `rep_PlayAnyVersion` plays replays of any FAF game version, as `/noversioncheck` does from the command line. A match the launcher starts can set switches at runtime, read as if they were on the command line.
- New switches, each on by default and listed in `docs/SWITCHES.md`: `sim_GatherOccupiedCells`, `ren_GlyphAdvanceOnly`, and the Lua and sim switches `sim_BlueprintLookupCache`, `sim_DepositIndex`, `lua_FastBindings` and `lua_GcPrefetch`.
- The nightly builds `faf-re-lua.nx2` against FAF's files of that night, so a FAF release no longer switches our interface fixes off.
- `faf_online`, the C++ client for FAF's lobby, API, replay vault and our control service, builds and runs on Windows, Linux and macOS; `faf-online-probe` signs in and lists games.

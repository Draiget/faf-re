# Golden maps

Generated by `python tools/mapformat/make_golden.py` (deterministic, fixed seeds, integer arithmetic for all samples:
re-running gives byte-identical files; `--check` compares instead of writing). The C++ reader and the Python reference
must both accept every valid file and both produce the stored dump. Do not edit by hand.

For every valid map there are `<name>.dump.txt` (the canonical dump of CONTAINER.md section 8, field names in
`tools/mapformat/DUMP_NAMES.md`) and `<name>.simhash` (64 hex digits + newline). Compression is zlib level 9 raw
deflate; the *decompressed* bytes are what the dumps and the simHash cover, so another deflate implementation
decoding these files is fine, but regenerating them needs the same zlib to be byte-identical.

## Valid maps

| File | What |
|---|---|
| `extended_min.fmap` | Only the required chunks `META GRID HGHT PLAY GPLY WBOD`: 64 x 48 cells (non-square), `stepLog2 = -7`, HGHT deflated, one global water body. requiredFeatures = `GRID_NONSQUARE`. |
| `extended_full.fmap` | Every Extended chunk (40 ids) with plausible content on a 64 x 48 grid, `stepLog2 = -8`, HGHT with Paeth predictor. Compressed and uncompressed chunks mixed; instances: `WFLW` 0..1, `SCDM` 0..1, `DRVD` 0..2 (`minmax_mips`, `nav_cache`, an unknown kind that must be ignored), `ASST` 0..1. Two water bodies besides the sea (polygon lake, mask river), three decks (flat / ramp / patch), a PLAY polygon, SIGN (fake key, not verifiable). |
| `full3d_full.fmap` | Container 4: everything of `extended_full` plus all 15 Full3D chunks. World of 2 x 1 x 2 cells (cellSize 32) with a non-zero f64 origin (`WORLD_LARGE_COORDS`), `MSHB` bundle 0 (a **12-byte placeholder** `glTF` + version 2 + length 12 for format 0, which the container does not validate, and a real native format-1 quad), bundle 1 (native triangle), `INST` in cells 0..2, `COLL` in cells 0 and 2 (triangle soup, hull, all five shape3d kinds), `NAVS` (height patch + triangle mesh + links), `VOLS`, two lightmap atlases, two probe volumes. |
| `extended_classic_equiv.fmap` | The subset that can express a Classic map: square 64 x 64, one global water body, `stepLog2 = -7`, `minHeight = 0`, one **dense** SPLT with 2 layers (materials from `MATL`), classic `LITE`, a few markers and props. |
| `unknown_optional_chunk.fmap` | `extended_min` plus a chunk `ZZZO` (not REQUIRED, not SIM). Must load; the reader reports the chunk as skipped (`chunk ZZZO inst=0 skipped`). Same simHash as `extended_min`. |
| `scatter_expected.txt` | The normative scatter result for `extended_full`'s first SCAT layer with the flat sampler (height 10.0, slope 0, material 0, surface 0, no holes, density map constant 1.0) over the whole 64 x 48 grid: `count` and the SHA-256 of the packed records (`u32 variant`, `f32 x, z, y, scale, yawDeg, tint`, little endian, 28 bytes each). Derivation in `tools/mapformat/mapfmt/scatter.py`. |

## Negative maps (all derived from `extended_min`; each must be refused for exactly the stated reason)

| File | Why it is refused | Reference error code |
|---|---|---|
| `bad_magic.fmap` | first byte changed: magic is not `0x1A70614D` | `BAD_MAGIC` |
| `bad_container_5.fmap` | container version 5 (header CRC fixed, so only the version is wrong) | `UNSUPPORTED_CONTAINER` |
| `bad_header_crc.fmap` | one header byte flipped, CRC left alone | `BAD_HEADER_CRC` |
| `truncated.fmap` | last 100 bytes cut: file shorter than `fileSize` | `TRUNCATED` |
| `bad_dir_crc.fmap` | one directory byte flipped, `dirCrc32` left alone | `BAD_DIR_CRC` |
| `bad_chunk_crc.fmap` | one byte inside GRID's stored data flipped | `BAD_CHUNK_CRC` |
| `chunk_out_of_range.fmap` | META's offset points past `dirOffset` (directory CRC and header CRC fixed) | `CHUNK_RANGE` |
| `unknown_required_chunk.fmap` | valid container; chunk `ZZZZ` carries the REQUIRED flag and is unknown | `UNKNOWN_REQUIRED_CHUNK` |
| `unsupported_required_feature.fmap` | valid container; `requiredFeatures` has bit 63 (`EXTENDED_FEATURES`) | `UNSUPPORTED_FEATURE` |
| `inflate_bomb.fmap` | HGHT declares `rawSize = 2000 x storedSize`, beyond deflate's 1:1032 maximum; refused before inflating | `INFLATE_RATIO` |
| `gpl_bad_surface_id.fmap` | valid container; GPLY plane holds surface id 5 which is not in the surface table (cross-chunk rule) | `CROSS_CHUNK` |

The reference error codes are the stable `code` of `MapFormatError` (see `tools/mapformat/mapfmt/errors.py`); the C++
reader only has to refuse the same files, with its own status names.
